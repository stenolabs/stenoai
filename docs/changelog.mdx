<Update label="v0.9.0" description="November 24, 2026">
**New**
- **Connect page**: open [Connect](/connect/overview) in the sidebar to link Steno with the Claude desktop app, Cursor, Claude Code and Codex. They read your meetings through a read-only Steno MCP server that runs on your computer.
- **What assistants can see**: limit MCP connections to chosen spaces, or to notes without transcripts, in Settings → Connectors.
- **Actions**: connect Linear, Notion, or Jira and Confluence, and Steno suggests follow-ups after each note. Edit a suggestion, then approve it; nothing is sent until you do. See [Actions](/connect/actions).
- **Email drafts**: approve an Email action to open a follow-up draft in your own mail app. No sign-in is needed, and nothing is sent until you press Send there.
- **Custom MCP servers**: add any MCP server by URL, such as an n8n, Zapier or Make workflow, or run one as a command on this computer. See [Custom MCP servers](/connect/custom-mcp-servers).
- **Actions in chat**: ask chat to create or change something in a connected app, and approve each change before it runs. This needs a model that can use tools; chat says so when the selected model can't.
- **Recipes**: save a chat prompt as a recipe and run it by typing `/` in Chat. Keep typing to filter the list. Nine built-in recipes include Write weekly recap, Decision log and Draft the follow-up.
- **Cookbooks**: browse the built-in note formats in a gallery, or write your own, from the new [Cookbooks](/features/cookbooks) page in the sidebar. Cookbooks replace report templates.
- **Always-editable notes**: click any part of a note and type. Changes save automatically, with no edit mode and no Save button. Cookbook reports are editable too. See [Editing notes](/features/editing-notes).
- **Instant transcripts**: with Parakeet, the labelled transcript and a first summary are ready right after Stop. Steno then refines both in the background. See [Instant transcripts](/features/instant-transcripts).
- **More chart types in chat**: ask for an area, pie, donut, scatter, radar or table chart, as well as bar and line. Copy a chart as an image, or copy its data as CSV.
- **OpenRouter**: choose OpenRouter as a cloud provider to reach many models with one API key.
- **New setup**: choose Local or Cloud in three short steps. Cloud setup links to the OpenRouter, OpenAI and Anthropic key pages and tests the key you paste. See [Get an API key](/getting-started/api-key).
- **Customisable record shortcut**: set your own combination in Settings → Preferences. The default is now `⌃⌥R` (`Ctrl+Alt+R` on Windows and Linux).

**Improved**
- Chat answers appear as they are written, with a Thinking trace that lists each step chat took.
- AI errors in chat say what went wrong and offer one fix, such as restarting the local model, updating the API key or opening AI settings.
- Folders are now called Spaces. Your existing folders and their notes are unchanged.
- Obsidian sync moved from Settings → Integrations to the Sync section of Connect.
- The model picker in Settings → AI shows friendly model names with a Fast, Balanced or Best hint.
- Home, Chat, Connect, Spaces and search show a next step when they are empty, and Home lists ways to start.
- First-run tips point out `/` recipes, Connect follow-ups and click-to-edit notes, one at a time.
- Home shows the record shortcut as key caps.
- Suggested action cards show the destination app's logo, and a finished action collapses to one line with an Open link.
- Chat's context chip sits inside the message box, and the note's ask bar shows it as an icon.
- The dragonfly mascot greets you in Chat and wears a hat for the holidays.
- Settings groups the meeting-start options in one section and nests the Hebrew model under Language.

**Fixed**
- Fixed an issue that could lose a chat answer if you left the conversation while it was being written.
- The transcript toggle in a note closes the transcript on a second click instead of reopening it.
- Charts render when the model fences them as `json` or without a language.
- Clicking anywhere on a provider card in setup selects it; previously only the card's header responded.
- Settings says transcription is on-device by default, because optional cloud transcription sends audio to the provider you configure.

**Known Issues**
- Updating from 0.8.0 installs but does not reopen Steno, because the app's name changed in 0.8.1. Open Steno from Applications once; later updates restart on their own.
- The record shortcut's default changed from `⌘⇧R` to `⌃⌥R`. If you relied on the old shortcut, set it again in Settings → Preferences.
- The Steno skill reads notes directly, so the "What assistants can see" limits apply only to MCP connections.
- Actions in chat need a tool-capable model. The default local model, Gemma 4 E2B, answers in plain text, as does organisation-managed AI.
- Slack, HubSpot, Asana and ChatGPT are listed on Connect as Coming soon. Until Slack is available, post to it through an n8n or Zapier workflow added as a custom MCP server.
- Instant transcripts need the Parakeet engine. With Whisper, the transcript and notes appear after transcription finishes.
- The Linux `.deb` is not attached to this release because it exceeds GitHub's 2 GiB asset limit. Use the AppImage instead.
- Windows and Linux installers remain unsigned. Linux updates are manual.
</Update>

<Update label="v0.8.1" description="November 23, 2026">
**New**
- **Edit generated notes**: change a saved note's generated sections while keeping the original model output available for recovery.
- **Share menu**: copy or export notes and transcripts from one menu, or send a note through the macOS share sheet.
- **Nemotron 3 speaker detection**: select this optional macOS engine in Settings → AI. Its models download before the engine changes; Sortformer remains the default.
- **Open meetings**: Steno can open a calendar meeting's link shortly before it starts. Choose Off, Ask or Automatically in Settings → Preferences.
- **Auto-record detected meetings**: turn this on in Settings → Preferences to start recording when Steno detects a meeting, without the Take Notes tap. A Recording started notification offers Stop. Off by default.
- **Identify call participants**: on macOS, put the other party of a phone or FaceTime call into a note's Participants by their Contacts name. Turn it on in Settings → Preferences; it needs the free iMCP app. Caller names reach the AI model, including cloud models. Off by default.
- **Hebrew transcription model**: with the Whisper engine, download the optional on-device ivrit.ai model in Settings → AI and turn it on. Hebrew recordings then use it automatically.
- **Recording timer in the menu bar**: on macOS, a red dot and the elapsed time appear next to the Steno icon while recording. A pause mark shows while paused.
- **Report properties**: custom reports show flat YAML frontmatter in a collapsible Properties panel and in PDF exports.

**Improved**
- Italian can be selected in transcription settings, and Auto can detect an Italian transcript instead of falling back to English.
- The Note ready notification shows how many action items the note has.
- Notifications wait their turn instead of replacing each other; Recording paused stays visible until you respond to it.
- Notifications appear on the display under the pointer. Other notifications do not appear over fullscreen presentations.
- The desktop app is named Steno again. If you saved a cloud API key, organisation sign-in or calendar access in v0.8.0, you may need to enter it again.
- Parakeet models download on managed networks that inspect secure connections. Set `SSL_CERT_FILE`, `REQUESTS_CA_BUNDLE` or `SSL_CERT_DIR` before starting Steno. Certificate errors now say whether the certificate expired, does not match the server or is not trusted.
- The website now has expanded government, defence, and law-enforcement pages, clearer navigation, and an app film.
- macOS release packaging includes MLX dependencies built for macOS 14 and checks the bundle's minimum OS version.
- A Traditional Chinese translation catalogue is prepared, but the interface still uses English until locale selection is available.

**Fixed**
- Fixed an issue that could leave a downloaded Parakeet model unable to load after a fresh install. Affected installs repair themselves without downloading again.
- Fixed an issue that could make first-run setup on Linux show no checks when no audio server is running.
- Calendar events keep their Google Meet or Outlook video link, which was previously dropped.
- Recording can use system audio alone when no microphone is present; a busy or denied microphone still stops the start.
- Live transcription stops when its capture view unmounts.
- Local settings and meeting requests keep working when the computer is offline.
- Changing cloud transcription settings preserves stored credentials and pending edits.
- Re-transcription includes every tracked segment of a continued note instead of dropping later parts.
- OpenAI-compatible providers can return text in typed chunks without breaking summaries or chat.
- A note being reprocessed keeps its original time in the notes list.
- Leaving a note with unsaved edits asks before discarding them.
- Fixed an issue that could make a recording started right after Stop report success without capturing audio.

**Known Issues**
- Continued notes created before segment tracking was added cannot be safely re-transcribed; Steno leaves them unchanged and explains why.
- Acoustic speaker separation and the macOS share sheet are macOS-only. Windows and Linux retain You / Others channel labels.
- Windows and Linux installers remain unsigned. Linux updates are manual.
</Update>

<Update label="v0.8.0" description="October 3, 2026">
**New**
- **Agents sidebar**: install the Steno skill in Claude Code or Codex using copyable prompts and the new [setup guide](/features/agents).
- **Charts in Chat**: ask for bar or line charts based on numbers in your notes, with a data table to inspect the values.
- **Chat during recording**: ask questions while recording and keep the conversation with the saved note. Parakeet supplies live transcript context; Whisper supplies transcript context after recording stops.
- **Meeting packages on macOS**: import and export `.stenomeeting` packages with notes, transcripts, and optional audio. Audio is excluded unless you select it.
- **Optional cloud transcription**: use an OpenAI-compatible endpoint after confirming that audio will be sent to the provider. Credentials are encrypted and tied to the configured endpoint.
- **What's new panel**: release highlights appear after an update when the app is idle. Reopen them from Settings → About.

**Improved**
- The macOS app download is smaller after removing unused libraries and reducing bundled audio and model runtimes.
- Speaker-separation models on macOS are now optional during setup and can be downloaded later in Settings → AI. Their download is smaller and shows progress.
- Parakeet downloads show byte totals and percentages when available, with a separate preparation stage.
- Supported audio in macOS meeting exports uses native AAC compression; original recordings stay unchanged.
- Linux packages retain Ollama's CUDA and Vulkan backends for supported GPUs and drivers.
- The installed app is named StenoAI; the website uses StenographAI. Existing data locations and download links remain compatible.

**Fixed**
- Numbered chat responses preserve their numbering across paragraphs and nested lists.
- Chat's rotating prompt examples no longer overlap.
- Note-generation failures show guidance for connection, model, authentication, timeout, memory, and configuration problems. Existing notes remain available for retry.

**Known Issues**
- Meeting package transfer and acoustic speaker separation are macOS-only. Windows and Linux retain You / Others channel labels.
- Windows and Linux installers remain unsigned. Linux updates are manual, and GPU support depends on the host hardware and drivers.
</Update>

<Update label="v0.7.1" description="September 5, 2026">
**New**
- **Linux alpha**: Debian/Ubuntu packages and an AppImage support microphone and PipeWire system-audio recording. Without PipeWire, recording uses the microphone only.

**Improved**

- Weekday and month names match the English interface. Times keep the system's 12/24-hour clock preference.
- The website and README use the StenoAI name, and the Government & Defence pages have been expanded.

**Fixed**
- Repeated folder-creation clicks no longer create duplicate sidebar folders, and failures are shown when a folder cannot be created.
- A recording that fails to start no longer leaves a stuck "Recording" entry in the meetings list.
- On Windows and Linux, the available live transcript replaces an ONNX batch transcript that successfully read less than half the recording.

**Known Issues**

- Acoustic multi-speaker identification remains macOS-only. Linux uses the existing `[You]` / `[Others]` channel labels.
</Update>

<Update label="v0.7.0" description="August 31, 2026">
**New**
- **Individual speaker labels (macOS)** — Steno now separates the voices that share one side of a call. A meeting with several remote participants reads as `Speaker 2`, `Speaker 3`, and so on, instead of collapsing everyone into a single `[Others]`. This runs on-device after the recording stops, and works whether the people are around one microphone or joining remotely.
- **Speaker identification** — Name a speaker once and Steno suggests that person in later meetings. This is off by default: turn it on under Settings → AI → Speaker identification. It creates a numerical voice profile, so enable it only if you have told the people you record and are authorised to do so. Anonymous per-meeting splitting keeps working with it off.
- **People management** — Settings → People lists everyone you have named, plays back the voice sample behind each profile, and deletes a person and their profile permanently. Recordings and transcripts are stored separately and are not deleted with a profile.
- **Review who is who** — When Steno is unsure, a review panel in the note offers excerpts you can play, lets you confirm or rename a speaker, mark a cluster as more than one person, or keep the generic label. It also says what a delete would cost before you confirm it.
- **FaceTime and Phone calls are detected** — Calls through FaceTime and Phone.app now trigger the meeting prompt like any other call.
- **Readable transcript export** — Exported transcripts now open with a clean conversation view that merges each speaker's consecutive lines into paragraphs, with the original timestamped transcript kept below it. Falls back to the raw transcript when timestamps aren't usable.
- **Russian** — Russian can now be selected in Settings → Transcribe, so summaries, titles and chat come back in Russian instead of defaulting to English. Available on both engines, and covered by auto-detect.

**Improved**
- Diarization is roughly 6.65x faster, using Sortformer's offline chunk preset.
- Processing shows live per-stage progress while speakers are being worked out, rather than one long opaque step.
- The Overview now marks which notes still have their original audio, so you can see what can be re-transcribed.
- Interrupted Parakeet model downloads resume instead of starting over.

**Fixed**
- macOS no longer shows an unexplained local-network prompt on first launch; Steno now declares why it needs local network access.
- An interrupted batch transcription now keeps what it managed to transcribe instead of discarding the whole run.

**Known Issues**
- Speaker separation is macOS-only. Windows keeps the existing `[You]` / `[Others]` channel labels.
- Speaker accuracy depends on recording quality; overlapping speech and shared microphones are the hardest cases.
- Selecting Russian pins the language of the summary, title and chat. Transcription accuracy for Russian on the default Parakeet engine has not been measured; switch to Whisper in Settings → AI if the transcript itself is poor.
</Update>

<Update label="v0.6.6" description="August 3, 2026">

**Improved**
- **One-tap meeting notes** — tapping "Take Notes" on a detected meeting starts recording immediately and opens the live note. - The About tab now says what actually failed when an update errors.
</Update>

<Update label="v0.6.5" description="July 26, 2026">

**Improved**

**Fixed**
- The macOS Keychain "Safe Storage" prompt no longer appears on every launch.
- The manual check-for-updates now follows redirects, so it keeps working after the download location moves.
- Opening Settings from a bare link now lands on General instead of stranding you on a stale tab.
- The AI's internal reasoning tags no longer leak into your notes in a few remaining cases.
