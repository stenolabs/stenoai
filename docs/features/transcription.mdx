description: "Steno transcribes recordings on-device by default with Parakeet and Whisper, with optional support for OpenAI-compatible cloud transcription endpoints."
---

Steno transcribes on-device by default using two local engines: **Parakeet** (the default, NVIDIA Parakeet TDT v3 running via MLX on Apple Silicon) and **Whisper** (an optional alternate, OpenAI's Whisper `large-v3-turbo`). Both run locally on your device -- your audio is never sent to any server unless you explicitly opt in to an **OpenAI-compatible ASR endpoint** in **Settings → AI → Transcription**.

## How it works

With the default Parakeet engine, a live transcript appears while you record, and Steno finalizes it when you stop. Whisper also processes audio locally, after you stop the recording. Both local engines output a verbatim transcript with timestamps. Cloud ASR runs after you stop and sends audio to your configured endpoint; timestamp and language support depend on the provider.

## Optional cloud transcription

In **Settings → AI → Transcription**, choose **Cloud API** and confirm the privacy notice. Enter your provider's API base URL, model name, and API key. Remote endpoints require HTTPS; HTTP is allowed only for loopback endpoints such as `localhost`.

The API key is stored encrypted on your device, separately from the summarisation key. Changing the endpoint to another provider requires saving a key for that provider. Use **Clear** to remove the saved key. Large recordings are split into smaller uploads automatically.

Cloud transcription sends recording audio off-device and may incur charges from your provider. Choose Parakeet or Whisper to return to local transcription. Parakeet remains the default on new installs.

## Language support

Language coverage depends on the engine. Steno auto-detects the language -- you do not need to set it manually.

- **Parakeet (default)** transcribes 25 European languages, including English, French, German, Spanish, Italian, Dutch, Portuguese, Russian, and Polish. A curated subset of six (English, French, German, Spanish, Dutch, Portuguese) can be pinned as the summary output language.
- **Whisper (optional)** covers the full set of 99 languages, including Japanese, Chinese, Korean, Hindi, and Arabic. To transcribe any of these, switch to the Whisper engine in **Settings → AI → Transcription**.

## Speaker labels

Transcripts include `[You]` and `[Others]` labels when system audio is enabled. `[You]` labels lines from your microphone; `[Others]` labels the audio from your speakers.

## Viewing the transcript

The full transcript appears in the right pane of any saved note, below the AI summary. Transcripts are also saved as plain text files in `~/Library/Application Support/stenoai/transcripts/`.

<Accordion title="Does Steno transcribe in real time?">
Yes. On macOS with the default Parakeet engine, a live transcript appears while you record. With Whisper or Cloud API, transcription runs after you stop the recording.
</Accordion>

<Accordion title="Can I edit the transcript?">
Transcripts are saved as plain text files. You can open and edit them in any text editor. Changes to the transcript file are reflected in Steno the next time you open the note.
</Accordion>
